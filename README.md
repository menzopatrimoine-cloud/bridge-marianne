# Le Bridge de Marianne

Application de bridge pour tablette : on joue en Sud contre trois robots qui annoncent selon les fiches d'un cours de bridge (Majeure 5e, 1SA 15-17, Stayman, Texas, 2 faibles, 2♣ fort, 2♦ forcing de manche…). Chaque enchère est expliquée, et un bouton « Conseil » propose l'enchère ou la carte recommandée.

Ouvrir la page dans Safari sur l'iPad, puis Partager → « Sur l'écran d'accueil ». L'application fonctionne ensuite sans internet.
